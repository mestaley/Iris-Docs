# 2026-11-02 — Scenes (activate_scene) — ADR-006 implemented

## Executive summary
Built the scene capability from ADR-006: a scene is a named set of Home Assistant actions applied
together ("movie time" → lamps to 10%, kitchen off). Iris-owned, defined in one hand-authored YAML
(`/etc/iris-fabric/scenes.yaml`) read by both services. curator presents `activate_scene(scene)` to the
model with the live scene list baked into the description (so semantic retrieval matches "time for a
movie"); tool-registry expands the call, firing the member `control_device` actions CONCURRENTLY through
the existing HA proxy + settle-verify, and aggregates changed/failed into a narratable result. Scenes
carry entity_ids (hand-authored config → stable, no mapping resolution needed in dispatch). Degrades
gracefully (no file / no pyyaml / parse error → the tool is simply absent, dispatch never breaks).
Built + tested on bastion; **not deployed** (needs merge/deploy + `uv sync` for pyyaml + the scenes file
+ an iris_tools re-seed). Mechanism is decoupled from any proactive trigger — Volition can call it later.
